Play the role of a senior C systems engineer with deep expertise in H.264/AVC, MPEG-TS, ISO/IEC 14496-10, FFmpeg/libavcodec internals, bitstream parsing, and broadcast stream analysis.

I am building a production-quality AVC/H.264 syntax parser in C for use inside a transport-stream probe/analyzer. The goal is not necessarily to reconstruct pixels, but to deeply inspect AVC bitstreams carried in MPEG-TS and extract useful structural metadata.

The parser should eventually handle:

- Annex B AVC NAL parsing
- EBSP-to-RBSP conversion
- NAL classification
- SPS parsing
- PPS parsing
- VUI parsing where useful
- SEI parsing where useful, especially recovery point and timing-related SEI
- AUD parsing
- slice header parsing
- access-unit boundary detection
- IDR/non-IDR classification
- frame_num, POC, field/MBAFF-related fields
- reference picture behavior
- safe random-access / safe decode-start analysis
- macroblock-layer syntax where practical
- CAVLC residual parsing if worthwhile
- CABAC residual parsing only if the engineering tradeoff makes sense

The previous design conclusion was that a complete parser down to macroblock residual CABAC/CAVLC decoding is effectively the entropy-decoding half of an AVC decoder. CABAC in particular requires arithmetic decoding, context initialization, hundreds of context models, neighboring macroblock state, syntax-element binarization, and residual significance/level decoding.

The recommended implementation stages were:

1. Build a clean bitreader:
   - read bits
   - read unsigned Exp-Golomb ue(v)
   - read signed Exp-Golomb se(v)
   - handle RBSP trailing bits correctly

2. Build Annex B NAL extraction:
   - detect 00 00 01 and 00 00 00 01 start codes
   - parse NAL headers
   - remove emulation-prevention bytes
   - produce RBSP buffers

3. Parse SPS:
   - profile_idc
   - constraint flags
   - level_idc
   - seq_parameter_set_id
   - chroma_format_idc
   - bit depths
   - log2_max_frame_num_minus4
   - pic_order_cnt_type
   - log2_max_pic_order_cnt_lsb_minus4
   - max_num_ref_frames
   - picture dimensions
   - frame_mbs_only_flag
   - mb_adaptive_frame_field_flag
   - cropping
   - VUI presence

4. Parse PPS:
   - pic_parameter_set_id
   - seq_parameter_set_id
   - entropy_coding_mode_flag
   - bottom_field_pic_order_in_frame_present_flag
   - slice groups / FMO
   - default reference counts
   - weighted prediction flags
   - initial QP values
   - deblocking control
   - constrained intra prediction
   - redundant picture count
   - transform_8x8_mode_flag
   - scaling matrix presence

5. Parse slice headers using active SPS/PPS:
   - first_mb_in_slice
   - slice_type
   - pic_parameter_set_id
   - frame_num
   - field_pic_flag
   - bottom_field_flag
   - idr_pic_id
   - pic_order_cnt_lsb
   - delta_pic_order_cnt fields
   - redundant_pic_cnt
   - direct_spatial_mv_pred_flag
   - reference index counts
   - cabac_init_idc
   - slice_qp_delta
   - deblocking filter fields

6. Implement access-unit detection by comparing VCL slice identity fields:
   - frame_num
   - pic_parameter_set_id
   - field_pic_flag
   - bottom_field_flag
   - nal_ref_idc zero/nonzero state
   - pic_order_cnt_lsb
   - delta_pic_order_cnt_bottom
   - delta_pic_order_cnt[0]
   - delta_pic_order_cnt[1]
   - IDR vs non-IDR
   - idr_pic_id

7. Add macroblock-layer parsing only after slice parsing is solid:
   - mb_skip_run or mb_skip_flag
   - mb_type
   - sub_mb_type
   - intra prediction modes
   - coded_block_pattern
   - transform_size_8x8_flag
   - mb_qp_delta

8. Add CAVLC residual parsing only if needed:
   - coeff_token
   - trailing_ones_sign_flag
   - level_prefix
   - level_suffix
   - total_zeros
   - run_before
   - static VLC tables

9. Treat CABAC as a major separate subsystem:
   - arithmetic decoder state
   - codIRange / codIOffset
   - rangeLPS tables
   - MPS/LPS transitions
   - context initialization from slice type, QP, and cabac_init_idc
   - context index derivation
   - macroblock neighbor availability
   - syntax-element binarization
   - significant_coeff_flag
   - last_significant_coeff_flag
   - coeff_abs_level_minus1
   - bypass and terminate bins

Important engineering preference:

For a production MPEG-TS probe, prioritize a robust syntax analyzer over a full residual decoder.
The most valuable early deliverable is:

- NAL classification
- SPS/PPS/VUI/SEI parsing
- slice-header parsing
- AU boundary detection
- IDR/recovery-point detection
- open-GOP / random-access safety analysis
- JSON metadata emission

Only move into macroblock residual CAVLC/CABAC parsing if there is a clear operational need
for coefficient-level inspection.
